## 문제:

최빈값 구하는 문제.
다음과 같은 문자열을 입력받았을 때, 어떤 알파벳이 가장 많이 포함되어 있는지 반환하시오. (단 최빈값을 가진 알파벳이 여러개일 경우 알파벳 순서가 가장 앞에 위치한 알파벳을 출력하시오)

"hello my name is dingcodingco"

## 정답:

```python
def find_max_occurred_alphabet(string):
    trimmed_string = string.replace(" ", "")  # 공백 제거

    my_dict = {}

    for char in trimmed_string:
        if my_dict.get(char):
            my_dict[char] += 1
        else:
            my_dict[char] = 1

    max_value = max(my_dict.values())

    my_list = []
    for key, value in my_dict.items():
        if value == max_value:
            my_list.append(key)

    if len(my_list) == 1:
        return my_list[0]
    else:
        result = my_list[0]
        for char in my_list:
            if char < result:
                result = char

    return result


string = "hello my name is dingcodingco"
result = find_max_occurred_alphabet(string)
print(result)
```

더 깔끔한 버전:

```python
def find_max_occurred_alphabet(string):
    counts = {}

    for char in string.replace(" ", ""):
        counts[char] = counts.get(char, 0) + 1

    max_count = max(counts.values())

    candidates = []
    for char, count in counts.items():
        if count == max_count:
            candidates.append(char)

    return min(candidates)
```
