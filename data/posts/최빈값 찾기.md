## 문제:

최빈값 구하는 문제

## 정답:

```python
def solution(array):
    mode_basket = {}
    # 배열을 순차적으로 순회해서 map으로 숫자:빈도수
    for number in array:
        if mode_basket.get(number):
            mode_basket[number] += 1
        else:
           mode_basket[number] = 1

    # 튜플로 해서 빈도수로 정렬
    tuple_mode = list(mode_basket.items())
    tuple_mode.sort(key=lambda x:-x[1])

    # 앞의 두 개 확인해서 숫자가 같으면 -1, 아니면 첫번째 숫자
    if len(tuple_mode) == 1:
        return tuple_mode[0][0]
    elif tuple_mode[0][1] == tuple_mode[1][1]:
        return -1
    else:
        return tuple_mode[0][0]
```

더 효율적인 방법:
(정렬은 O(nlogn)이라서, O(n)으로 해결 가능)

```python
def solution(array):
    counts = {}

    for num in array:
        counts[num] = counts.get(num, 0) + 1

    max_count = max(counts.values())

    modes = []
    for num, count in counts.items():
        if count == max_count:
            modes.append(num)

    if len(modes) > 1:
        return -1

    return modes[0]
```
